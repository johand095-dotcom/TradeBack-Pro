# Tradeback Pro

A web-based vehicle trade-back inspection app for ELT Group (PTY) Ltd.

## Features
- Unique inspection number
- Vehicle and inspector details
- Item-by-item inspection checklist
- Photo evidence required for failed items
- Comments and conclusion section
- Digital signature capture
- PDF report download
- Local draft save/load on the same device

## Use
Open `index.html` in a browser, or host the folder with GitHub Pages.

## GitHub Pages deployment
1. Upload these files to the `Tradeback-Pro` repository.
2. Go to Repository Settings > Pages.
3. Set source to the main branch and root folder.
4. Open the published GitHub Pages link.

## Customising checklist items
Edit `checklistData` in `app.js` to match the original Excel inspection sheet exactly.
